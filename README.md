# DaněNula.cz

Professional website for tax filing services specializing in zero-tax declarations for inactive businesses and self-employed individuals in the Czech Republic.

## Features

- Clean, professional design with white background and emerald green accents
- Responsive navigation with mobile menu
- Smooth scroll animations
- Intelligent form with automatic input formatting
- GDPR compliant data collection

## Technologies

- HTML5
- CSS3 (Custom Properties)
- Vanilla JavaScript
- Google Fonts (Inter)

## Running Locally

```bash
npx -y serve .
```

Then open http://localhost:3000 in your browser.
